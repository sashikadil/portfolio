# Sashika Dilshan – Personal Portfolio

## Folders
- website/        The live site. Upload this folder's contents to GitHub, then deploy on Vercel.
  - index.html    The whole page (HTML + CSS + newsletter script)
  - images/       Compressed photo and client logos (.webp)
- design-source/  Editable design files from the Claude design canvas (Main.dc.html is the page)
- assets/         Full-size originals: your photo (original + cut-out) and client logos (.png)

## Newsletter
The signup form posts to Kit form 10179817. New subscribers appear in Kit > Subscribers.

## Deploy
GitHub repo -> Vercel > Add New > Project > import repo > Deploy (Framework: Other).
